# ORBITA

Página web estática y adaptable a móviles. No requiere servidores, cuentas ni dependencias.

## Publicación en GitHub Pages
1. Descomprime el archivo ZIP.
2. Crea un repositorio público en GitHub.
3. Sube `index.html` y `README.md` a la raíz.
4. En Settings → Pages selecciona Deploy from a branch, `main` y `/(root)`.

También puedes abrir `index.html` directamente en tu navegador.
